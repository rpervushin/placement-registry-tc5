RecSys

конфиги плейсментов
~1–2 дня
1. Эндпоинт — список плейсментов обязательно для MVP
  • Новый метод: GET /recsys/api/placements
  • Возвращает все заведённые плейсменты с текущим конфигом
  • Реестр опрашивает раз в 15 мин (polling)
  • Аутентификация: service-to-service JWT
// Ответ — массив объектов:
[{
  "placement_id": "main.personal_recommendation",
  "status":       "active",
  "model":         "bert4rec-v3",
  "ranking_type":  "personalized",
  "personalized":  true,
  "fallback":      "top-popular",
  "ab_test": {
    "active":       true,
    "variant":      "B",
    "started_at":   "2026-05-01"
  },
  "updated_at":    "2026-05-26T08:12:00Z"
}]
2. Webhook при изменении конфига желательно
  • При изменении конфига/статуса/AB-теста — POST /registry/sync
  • Тело: тот же объект из п.1 для конкретного плейсмента
  • Даёт real-time актуальность вместо 15-минутного лага
  • Можно сделать после polling — как второй шаг
📦

MS Catalog

мониторинг по /context
~2–4 часа
3. Метрики /context по placement_id обязательно для MVP
  • В Grafana/Prometheus уже есть метрики ручки /context
  • Нужно уточнить: какой label = placement_id в метриках
  • Реестр подключится к Grafana напрямую (read-only datasource) — новый код в Catalog не нужен
  • Что реестр будет смотреть: RPS, p95 latency, error rate, last_request — в разрезе каждого placement_id
// Пример Prometheus-запроса (реестр делает сам):
sum(rate(http_requests_total{
  handler="/context",
  placement_id=~".*"
}[5m])) by (placement_id)
4. Read-доступ к Grafana желательно
  • Создать service account с ролью Viewer в Grafana
  • Или дать read-only токен к Prometheus datasource
  • Задача для DevOps / платформенной команды

❓ Вопросы для уточнения на встрече

RecSys

Существует ли уже внутренний API со списком плейсментов и конфигов? Если да — достаточно добавить внешний маршрут и сериализацию.

RecSys

Каков формат placement_id внутри RecSys? Нужно убедиться, что он совпадает с тем, что МП передаёт в запросе — чтобы реестр использовал единый идентификатор.

RecSys

Где хранится AB-статус? В RecSys или в AB-платформе X5? Кто является source of truth для статуса эксперимента?

Каталог

Под каким label в Prometheus логируется placement_id? Нужно имя label для построения запросов мониторинга в реестре.

Каталог

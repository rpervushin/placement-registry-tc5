# Placement Registry TC5

Реестр товарных подборок (плейсментов) в мобильном приложении Торговой Сети X5.

## Статус (актуализировано 2026-08-27)

Единственный источник истины по проекту. Ранее часть материалов дублировалась в
`rpervushin/placement-registry-mvp-tc5` — тот репозиторий архивирован, весь актуальный
контент перенесён сюда.

У реестра две функции:

1. **MVP — учёт плейсментов рекомендаций.** Единый реестр всех рекомендательных плейсментов
   в МП и их настроек — метод, модель RecSys, id плейсмента, статус, экран размещения.
   Данные приходят из RecSys (входящая интеграция).
2. **Этап 3 — управление правилами встраивания медиа-объектов.** Для каждого плейсмента:
   приоритет и fallback-цепочка стейкхолдеров (X5 Media, Маркетинг, Контент, Рецепты,
   Трейд-промо), разрешённые типы промотируемых объектов и их частота, правила
   разнообразия, глобальные настройки, метрики. Реестр не участвует в обработке запроса
   пользователя — MS Catalog применяет правила при формировании выдачи. Оценка разработки —
   в разработке (см. `TASKS.md`).

Отдельно — открытый архитектурный вопрос о том, где во время обработки запроса пользователя
происходит слияние рекомендаций со встраиваемыми объектами: в MS Catalog или в Splitter BFF
(см. `ARCHITECTURE.md` §12). Решение не принято.

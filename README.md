# Placement Registry TC5

Реестр товарных подборок (плейсментов) в мобильном приложении Торговой Сети X5.

## О проекте

**MVP-цель:** сервис учёта (инвентаризация + визуализация), не управления.  
Данные приходят из внешних систем: RecSys, X5 Media Admin, Trade-Promo Admin, Loyalty Service.

## Структура

```
placement-registry-mvp.html      — MVP-прототип v0.2 (учёт + мониторинг)
placement-registry-prototype.html — прототип v1 (полный функционал, для сравнения)
v1-archive/                      — архив первой версии
docs/                            — проектные материалы (PDF, DOCX, карта экранов)
```

## Что в MVP

- Read-only реестр всех подборок с фильтрацией
- Карта плейсментов по экранам МП
- Discovery-события (авторегистрация новых placement_id)
- Раздел «Интеграция» с описанием механизмов синхронизации
- API контракт (только GET + входящие sync-эндпоинты)

## Что исключено из MVP

- Управление статусом подборок
- Переключение моделей ранжирования
- Создание плейсментов из реестра
- Ручное редактирование конфигурации (blender, ranking_type)
